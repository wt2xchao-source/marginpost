# MarginPost V0.3.0 Release Notes

Release date: 2026-09-24

## Highlights

- Review Markdown create, modify, delete, and rename events.
- Understand which Change Sets are pending, superseded, or stale.
- Compare historical versions with the same structured Markdown diff engine.
- Move between changes, decide by keyboard, and undo the latest decision.
- Search workspace files and filter the review inbox.
- Integrate optional source labels with Claude Code, Codex, and Cursor.
